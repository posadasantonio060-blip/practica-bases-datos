# Preguntas de reflexión

57. ¿Cuál es la diferencia entre una base de datos y una tabla?
Una base de datos contiene y organiza la información; una tabla es una estructura dentro de ella formada por filas y columnas.

58. ¿Qué diferencia existe entre una fila y una columna?
Una fila representa un registro completo y una columna representa una característica o campo.

59. ¿Para qué sirve SELECT?
Sirve para consultar información almacenada en una tabla.

60. ¿Para qué sirve WHERE?
Sirve para establecer una condición y seleccionar registros específicos.

61. ¿Qué función tiene UPDATE?
Permite modificar información existente.

62. ¿Por qué es importante utilizar WHERE al modificar información?
Porque permite indicar qué registro debe modificarse y evita cambiar todos los registros por accidente.

63. ¿Qué puede ocurrir si utilizamos DELETE sin WHERE?
Se pueden eliminar todos los registros de la tabla.

64. ¿Qué tipo de información se puede almacenar en una columna INT?
Números enteros.

65. ¿Qué diferencia existe entre INSERT, UPDATE y DELETE?
INSERT agrega registros, UPDATE modifica registros y DELETE elimina registros.

66. ¿Qué ventaja encontraste al utilizar GitHub para guardar tu práctica?
Permite mantener los archivos organizados, respaldados y disponibles mediante un enlace para entregarlos y revisarlos.
